# Research and Compute Multiplication Contract

Date: 2026-10-01
Purpose: maximize national acquisition research/collector-development throughput without duplicating work, weakening evidence gates, or creating a second canonical scheduler.

## Authority
HERMES remains the sole canonical scheduler/resource authority for canonical civic work. This contract governs research acceleration and collector development. Research tools do not publish canonical truth.

## Mandatory tool allocation
For each unresolved source-family/government/election-authority obligation, assign one primary discovery lane and optional independent verification lane. Do not spray every tool at every target.

### Exa
Use for semantic discovery of authoritative rosters, candidate filing systems, election authorities, documentation and recurring vendor/CMS families.

### Tavily / Parallel Search
Use for parallel source discovery, cross-checking authority domains, and filling discovery gaps not efficiently covered by deterministic directories.

### Firecrawl
Use for bounded mapping/crawling/extraction of known public sites when multiple related pages must be enumerated. Convert stable discoveries into deterministic collectors.

### TinyFish / browser execution
Use only for difficult JS/interactive portals or workflow discovery. Once a stable endpoint/feed/document is identified, prefer deterministic retrieval.

### Legal Data Hunter
Use for judicial/legal/ethics/public-record source discovery and later evidence enrichment where relevant.

### Acumen/Talarion
Use as omission/current-state research QA: identify what the research plan may have missed. Do not use as canonical evidence.

### Wolfram
Use for computation/normalization/verification tasks where its structured computation adds value; it is not a civic primary source.

### Cloudflare
Use as scalable deterministic execution fabric for lightweight HTTP acquisition, queues, scheduled source checks, signatures, fanout and retry/dead-letter routing within canonical work identity/source policy.

### Existing VPS
Reserve for HERMES authority, integration-sensitive work, parsing/validation/evidence, bounded GIS, browser and local-model work.

### GitHub Actions
Engineering only: parser tests, regression fixtures, contract drift, CI and maintenance. Never a second production civic scheduler.

### Railway/Vercel/Hugging Face/other free tiers
Research/evaluate only until a specific workload has measured benefit and current terms permit it. Do not provision recurring infrastructure or create paid dependencies without Owner authorization.

## Escalation ladder
Prefer the cheapest reliable path that satisfies the ResearchContract:
1. existing current canonical evidence/cache
2. authoritative structured API/download
3. deterministic HTTP/document retrieval
4. reusable parser/source-family adapter
5. Cloudflare distributed execution
6. research/search accelerator
7. browser workflow discovery
8. local model
9. approved external reasoning

Correctness/source requirements override cost ordering.

## National Candidate Factory accelerators
Seed state election-authority discovery from official national directories such as USAGov/FEC, then resolve each state's authoritative candidate filing/qualification/certification/result sources.

Where states expose downloadable candidate files, prefer bulk/download ingestion over person-by-person queries.

Use the Voting Information Project data model/specification as a normalization cross-check for election administration, electoral districts, offices, candidate contests, candidates, retention contests and source metadata. VIP is not a substitute for primary election authority.

Federal candidate filing discovery begins with FEC 2025-2026 bulk/API data, but FEC candidacy/filing is not ballot qualification. Qualification/certification must be reconciled against the applicable election authority.

## ResearchWorkIdentity / dedupe
Every research obligation must have stable identity by geography/government/source-family/cycle/scope. Before launching a research accelerator, check existing source registry, reservations, prior observations and active work. Duplicate discovery is a failure mode.

## Discovery -> production conversion
A successful research result should end in one of:
- authoritative source registered;
- deterministic adapter/parser family created or extended;
- source-family classification improved;
- explicit truthful blocker;
- browser-only exception documented;
- monitoring signature established.

Do not leave repeatable source acquisition permanently dependent on an expensive search/model tool if deterministic collection is practical.

## Quota/cost telemetry
Track tool/provider calls, successes, authoritative sources discovered, deterministic conversions, failure/blocked reasons, and approximate quota/cost class. Optimize verified relationships and reusable source families per research call, not raw request count.

## Parallel lanes
Safe parallel research lanes include:
- government/Seat structure;
- current-official roster families;
- state election/candidate systems;
- local election/candidate systems;
- judicial/retention systems;
- school/special-district structures;
- identity/currentness exceptions;
- monitoring/change signatures.

HERMES/ResearchWorkIdentity prevents two lanes from rediscovering the same authority.

## Safety
Respect terms, robots/access controls where applicable, rate limits and source policy. Do not bypass CAPTCHA or access controls. No paid signups/accounts/infrastructure without Owner authorization.
