# Swarm Reconciliation and Execution Map

## Recovered generations
### Generation A
HERMES Prime + H1-H32 officeholder/Seat + C1-C32 candidate = 65 top-level logical roles.

### Generation B
H1-H46 + C1-C36 + E1-E16 + Q1-Q4 = 102 logical named responsibilities.
These are a completeness/responsibility taxonomy, not evidence of 102 independent physical collectors.

### Current canonical direction
The later architecture consolidates responsibilities into reusable capability contracts and physical worker pools. Existing canon explicitly says logical capabilities are responsibilities and physical workers are execution pools.

## Preservation rule
Do not discard H/C/E/Q responsibilities. Crosswalk each to current canonical capability keys and mark:
COVERED / PARTIAL / MISSING / SUPERSEDED / RESEARCH_ONLY.
For each capability record:
- implementing module/process;
- queue/wakeup;
- required tools/source policy;
- last real job;
- last retrieval/evidence;
- backlog;
- failure state;
- scaling class.

## Execution departments
1. HERMES Executive: one canonical scheduling/resource authority.
2. Government/Seat Discovery: Census seed, authority discovery, office/Seat enumeration.
3. Official Acquisition: roster/feed discovery, deterministic collection, parsing.
4. Election/Candidate: election authority, cycles, filings, qualification, results.
5. Identity/Currentness: Person resolution, occupancy, vacancy, temporal validity.
6. Evidence/Validation: artifacts, hashes, locators, canonical gates.
7. Monitoring/Change: signatures, source health, deltas, due checks.
8. GIS/Boundary: jurisdiction and Seat geography.
9. Browser Exception: only dynamic sites not solvable by deterministic retrieval.
10. Model/Semantic: bounded evidence-backed semantic extraction.
11. Quality/Coverage: Q responsibilities, finite reconciliation, gaps, contradiction.
12. Academy: turn repeated source patterns/failures into tested deterministic adapters.

## Horizontal scale rule
Scale compatible queue consumers beneath HERMES. Never instantiate one server/process per historical agent ID. Never create duplicate source-discovery lanes for the same authority.

## Required first artifact
Create a machine-readable 102-role -> current-capability crosswalk before declaring swarm reconciliation complete.
