# National Acquisition Waves and Acceptance Gates

## Wave A — Universe + Swarm Reconciliation
Deliver:
- exact 2026 Census government seed ingestion plan/data lineage;
- computed Seat-registry methodology;
- live Seat denominator fields with as-of;
- 102-role historical crosswalk to current capabilities;
- physical worker/queue/service map;
- resource baseline and queue baseline.

Exit only with durable evidence. No invented national Seat total.

## Wave B — Florida Production Commissioning
Use already-built Florida 67-county inventory, VoterFocus family, direct-authority parsers, authority/currentness gates and telemetry. Do not redo Florida research.
Commission bounded cohorts first, measure:
official observations/day; verified occupancies/day; identity obligations/day; identity validations/day; source/parser throughput; backlog/age; failure rate.
Ramp only after validation/storage stay healthy.

## Wave C — National Government Universe
Ingest the 2026 government universe and create deduplicated government/authority/Seat-discovery obligations by state and government type.

## Wave D — Official Factory National Expansion
Run reusable source-family factories across federal/state/county/municipal/township/school/special-district structures. Convert recurring discoveries into deterministic adapters through Academy.

## Wave E — Candidate/Election Factory
Run concurrently with D. Federal FEC + authoritative ballot sources; state filing/certification systems; local election authorities. Reconcile filing/qualification/withdrawal/result status and Seat linkage.

## Wave F — Hard/Long-Tail Structures
Close municipalities, school districts, special districts, judiciary/retention, unusual election structures, GIS and dynamic portals.

## Wave G — Monitoring + Coverage Closure
Turn authoritative sources into scheduled signature checks, delta work, discrepancy repair and honest coverage closure.

## Universal gate
For every wave report:
source/Accepted/Recovery lineage; tests; source objects; Seats discovered/expected; occupancy coverage; election-authority coverage; CandidateCampaigns; unresolved identities; evidence; monitoring readiness; queue depths; oldest work; throughput; resource utilization; failures/blockers.

Checkpoint is not a stop condition. Continue unless a genuine authorization/security/corruption/destructive-production boundary is reached.
