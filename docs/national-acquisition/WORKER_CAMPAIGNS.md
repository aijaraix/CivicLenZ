# Substantial Non-Overlapping Worker Campaigns

Do not start all campaigns by creating separate authority. HERMES remains the single canonical authority. Workers receive bounded implementation scopes and use current Worker-first authorization.

## Worker 1 — National Universe + Seat Factory
Own:
- 2026 Census government universe ingestion;
- government normalization;
- authoritative-domain/structure discovery obligations;
- elected/appointed/retention Seat derivation;
- live denominator/as-of metrics;
- 102-role -> current-capability crosswalk artifact where coupled to coverage planning.
Do not own incumbent roster parsing or candidate feeds except interfaces/contracts.

## Worker 2 — Official Acquisition + Florida Commissioning
Own:
- commission existing Florida collector foundation;
- measure real canonical throughput;
- expand reusable official-roster source families;
- source-family parsers/adapters and authority/currentness handling.
Do not own CandidateCampaign implementation.

## Worker 3 — Election + Candidate Factory
Own:
- Election/CandidateCampaign model gaps;
- FEC acquisition interfaces;
- state/local candidate filing, qualification, certification and results source families;
- Seat/Election/Person linkage;
- active-cycle monitoring.
Do not rebuild incumbent roster factory.

## Worker 4 — Monitoring + Coverage + Resource Scaling
Own:
- source signatures/change detection;
- monitoring obligations/deltas;
- coverage metrics;
- queue/resource telemetry;
- Resource Governor tuning from measured load;
- safe Cloudflare fanout and backpressure.
Do not become a second scheduler.

## Parallelization
Workers may run concurrently only after exact governed source is revalidated and file/scope boundaries are assigned. Shared files/contracts require explicit coordination and integration order.

## Preservation
Each coherent application checkpoint:
COMMIT -> Gateway -> Internal Forge -> immutable Recovery -> Accepted -> VERIFY.
No production deployment without a separately authorized deployment gate.
